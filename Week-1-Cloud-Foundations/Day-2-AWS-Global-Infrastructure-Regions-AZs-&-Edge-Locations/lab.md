# Week 1 - Day 2: Lab - Map AWS Regions & Build Infrastructure Cheat Sheet

**Objective**: Explore AWS Global Infrastructure and create your first portfolio artifact.

---

## ✅ Prerequisites
- AWS Free Tier Account (completed Day 1)
- GitHub Account

---

## Lab Steps

### Step 1: Explore AWS Global Infrastructure Map

1. Visit [https://infrastructure.aws](https://infrastructure.aws)
2. Identify all Regions in Africa → Note `af-south-1` (Cape Town)
3. Check US East (N. Virginia) `us-east-1` — note number of AZs
4. Check `af-south-1` — note AZ count and available services
5. Find nearest Edge Locations to Nigeria (Lagos/West Africa)

### Step 2: Verify in AWS Console

1. Log into AWS Management Console
2. Check total Regions in the Region selector
3. Switch to `af-south-1` (Cape Town)
4. Switch back to `us-east-1`
5. In EC2 Dashboard, view Availability Zones for the current Region

### Step 3: Build Your Cheat Sheet

Create a table with these columns:
- Region Name
- Region Code
- AZ Count
- Key Services
- Notes

**Required Entries**:
- `us-east-1`
- `us-west-2`
- `eu-west-1`
- `af-south-1`
- `ap-southeast-1`
- `sa-east-1`

### Step 4: Publish to GitHub

1. Go to [https://gist.github.com](https://gist.github.com)
2. Create a public Gist titled `AWS Regions Cheat Sheet - Week 1`
3. Copy the Gist URL (your first portfolio artifact)
